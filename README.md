# TrendRadar

Система раннего обнаружения трендов Roblox. Собирает не только то, что
происходит внутри платформы, но и то, откуда тренды приходят.

**Тренды в Roblox почти никогда не зарождаются в Roblox.** Они приходят
снаружи и материализуются там через дни или недели. Поэтому источников пять,
а не один.

## Пять источников, все бесплатные и без ключей

| Источник | Что даёт | Опережение |
|---|---|---|
| **Roblox** | 7 чартов, CCU, визиты, избранное, лайки, серверы, реклама | 0 |
| **YouTube (9 языков)** | загрузки 100+ каналов, просмотры/час, мультиязычность | 1–10 дней |
| **Steam** | топ по онлайну + жанры → что склоняют в Roblox | 2–4 недели |
| **AniList** | календарь аниме-премьер → IP-волна клонов | 1–4 недели |
| **DevForum** | фичи платформы и ранние билды | 2–8 недель |

Проверено вживую: **429 игр, 86 каналов, 1157 видео, 54 упоминания
в 5 языках, 122 внешних сигнала.**

## Установка — подробно, первый раз

Нужен только **Python 3.10+**. Всё остальное поставится само.

### Windows — самый простой путь

1. Скачай Python с **python.org** и при установке **обязательно** поставь
   галочку **«Add Python to PATH»**. Рекомендую версию 3.11 или 3.12.
2. Распакуй архив. Открой получившуюся папку `trendradar` — внутри должны быть
   `README.md`, `src`, `scripts` и файл **`setup.bat`**.
3. **Двойной клик по `setup.bat`.** Всё.

Окно откроется само, поставит зависимости (2–4 минуты), создаст базу и покажет,
что запускать дальше. Если что-то пойдёт не так — окно не закроется и покажет
ошибку по-английски.

### Windows — если нужен PowerShell

```powershell
.\scripts\setup.ps1
```

Если PowerShell блокирует запуск скриптов:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
```

Скрипты написаны **только латиницей**. Это не косметика: PowerShell 5.1 на
русской Windows читает `.ps1` без BOM-маркера как ANSI, и любой русский текст
внутри файла превращается в мусор, ломая парсер с ошибкой
«Непредвиденная лексема». Поэтому сообщения в скриптах английские, а не русские.

### macOS / Linux

```bash
cd ~/trendradar
bash scripts/setup.sh
```

Скрипт создаёт виртуальное окружение, ставит зависимости и базу.
Дальше каждый раз перед работой активируй окружение:

```bash
source .venv/bin/activate        # macOS / Linux
. .\.venv\Scripts\Activate.ps1   # Windows
```

### Первый сбор данных

```bash
python src/collect.py            # Roblox: ~40 сек
python src/youtube_collect.py --seed        # 35 каналов в 9 языках
python src/youtube_collect.py --discover-lang   # +60 каналов
python src/origins.py            # Steam + аниме + DevForum (~2 мин)
python src/report.py             # отчёт в reports/
streamlit run dashboard/app.py   # браузер откроется сам
```

Первый запуск скачает модель эмбеддингов (~120 МБ), это одна минута.

### Если что-то не так

| Симптом | Причина | Что делать |
|---|---|---|
| `python: command not found` | Python не в PATH | переустанови с галочкой «Add to PATH» |
| `No module named streamlit` | окружение не активировано | выполни `source .venv/bin/activate` |
| `unable to open database file` | нет папки `data/` | создастся сама при `python src/db.py` |
| Долго качает при старте | скачивается модель эмбеддингов | один раз, ~120 МБ |

## Как видео привязывается к игре

Три прохода, от точного к приблизительному. Каждое упоминание хранит `method`,
так что видно, чему можно верить.

| Проход | Что делает | Точность | Языки |
|---|---|---|---|
| `link` | ссылка на игру в описании видео → placeId → игра | точный | любые |
| `token` | название игры внутри заголовка | высокая | любые, если название латиницей |
| `embed` | многоязычная семантика для остального | ~85–90% | любые |

**link** ещё и находит игры вне чартов: если автор дал ссылку на игру, которой
нет в базе, она подтягивается и добавляется. Это первый ответ на слепое пятно
«видим только игры из чартов».

**embed** — модель `paraphrase-multilingual-MiniLM-L12-v2` (ONNX, без torch,
~120 МБ). Цифры, на которых выбраны пороги, а не угаданы:
- эмбеддинги целых заголовков бесполезны: 39% согласия, сотни ложных срабатываний —
  модель ловит тему «видео про Roblox», а не имя игры;
- на коротких окнах мешает «хабность»: некоторые игры (например WorldFront) близки
  ко всему, и фраза «ВСЕ МУТАЦИИ» получала 0.94;
- лечится поправкой CSLS: `2·cos − hub(игра)`;
- порог 1.15 для кириллицы/арабского/CJK и 1.30 для латиницы (там токенный проход
  уже отработал, а то, что он пропустил — в основном общие слова).

Примеры реальных попаданий: «مزرعة دجاج» → Chicken Farm, «الامتحان» → Examination,
«Xây Dựng Pyramid» → Build the Pyramid.

## Модули

**`embed.py`** — многоязычный матчер, индекс игр кэшируется на диск.
**`match.py`** — link + token проходы.
**`origins.py`** — Steam, AniList, DevForum. Пишет и текущее состояние, и
историю по дням (`origin_history`); `trends()` считает, что реально растёт.
**`link.py`** — привязка внешних сигналов к нишам Roblox и IP-матчинг.
**`youtube_collect.py`** — мультиязычный сбор, 9 языков, автообнаружение каналов.
**`features.py`** — momentum, YouTube, реклама, **ранг внутри когорты** (возраст × размер).
**`templates.py`** — шаблоны названий со **стабильным ключом** (`family_key`).

## Что исправлено в этой версии

- **Многоязычность работала только на латинице.** Теперь три прохода; арабские,
  вьетнамские, турецкие заголовки с переведённым названием находятся.
- **`lifetime_ratio` завышал старые игры.** Заброшенная игра 2013 года давала
  космический коэффициент. Теперь скор — это процентиль внутри когорты
  «возраст × размер», а не абсолютное число.
- **`family_id` менялся между запусками.** Теперь `family_key` = хеш ядра токенов.
  Проверено: перемешивание данных даёт идентичные ключи.
- **Внешние сигналы перезаписывались.** Добавлена `origin_history`: одна точка в день
  на сигнал, без дублей при повторных запусках. `trends()` показывает рост, а при
  одном дне данных честно возвращает пусто.
- **Старая БД ломалась при обновлении схемы.** `create_all()` не добавляет колонки,
  поэтому добавлена автомиграция (`ALTER TABLE`) — база с прошлой версии открывается.
- **Скобки в заголовках.** «(ROBLOX Jailbreak)» вырезалось как мусор, а это и было
  название игры. Для заголовков скобки теперь сохраняются, для названий игр — нет.
- **«PICK A DOOR» матчилось на игру «DOORS»** — стемминг сводил «door» и «doors»
  к одному слову. Для односложных названий сравнение теперь по буквальной форме.
- **Дашборд**: убраны устаревшие параметры, проверен программно.

## GitHub — пошагово, с нуля

Что нажать и что вставить. Ничего знать заранее не нужно.

### Шаг 1. Аккаунт

Открой **github.com** → `Sign up` → почта, пароль, имя пользователя.
Подтверди почту. Бесплатного плана достаточно, карта не нужна.

### Шаг 2. Создать репозиторий

1. Справа сверху `+` → `New repository`.
2. **Repository name**: `trendradar`
3. Выбери **Public**. Это важно: на приватном бесплатно только 2000 минут
   в месяц, на публичном запуски бесплатны без лимита.
4. **Не ставь галочки** «Add a README», «Add .gitignore», «Choose a license» —
   они создадут файлы и помешают первой загрузке.
5. `Create repository`.

Появится пустая страница с подсказками команд. Так и должно быть.

### Шаг 3. Поставить Git

- **Windows**: скачай с **git-scm.com**, установи со всеми настройками по умолчанию.
- **macOS**: в терминале `git --version`, система сама предложит установить.
- **Linux**: `sudo apt install git`

Проверь: `git --version`

### Шаг 4. Представиться Git'у (один раз)

```bash
git config --global user.name "Твоё Имя"
git config --global user.email "почта@как-на-github.com"
```

Почта должна совпадать с аккаунтом GitHub, иначе коммиты не засчитаются.

### Шаг 5. Загрузить файлы

Распакуй архив и зайди в папку `trendradar` — туда, где лежат `README.md`,
`src`, `dashboard`. В **этой** папке открой терминал
(Windows: клик по адресной строке проводника → набери `powershell` → Enter).

```bash
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/ТВОЙ_НИК/trendradar.git
git push -u origin main
```

`ТВОЙ_НИК` замени на свой логин. Ссылку можно скопировать на странице
репозитория кнопкой `Code`.

При `git push` попросит логин и пароль. **Пароль от аккаунта не подойдёт** —
нужен токен:

1. Аватар → `Settings` → внизу `Developer settings`
2. `Personal access tokens` → `Tokens (classic)` → `Generate new token (classic)`
3. Note: `trendradar`, Expiration: `90 days`, галочка **`repo`**
4. `Generate token` → скопируй строку `ghp_...`

Вставь её вместо пароля. Логин — обычный ник. Токен показывается один раз,
сохрани его.

### Шаг 6. Включить автоматический сбор

1. Вкладка **Actions** вверху репозитория.
2. Если видишь баннер «Workflows aren't being run on this repository» —
   нажми `I understand my workflows, go ahead and enable them`.
3. Слева выбери **collect**.
4. Справа `Run workflow` → зелёная кнопка `Run workflow`.
5. Обнови страницу через минуту: жёлтая точка — идёт, зелёная галочка — готово,
   красный крест — ошибка.

Дальше он запускается сам каждые 15 минут. Держать компьютер включённым не надо.

### Шаг 7. Смотреть результаты

**А — отчёт прямо на GitHub.** После каждого запуска обновляется
`reports/ГГГГ-ММ-ДД.md`. Открой его в репозитории — таблицы отрисуются там же.

**Б — скачать.** `Actions` → `collect` → последний запуск → внизу `Artifacts`
→ `db-...` → скачать zip. Внутри база и все отчёты.

**В — живой дашборд с графиками.**

1. Зайди на **share.streamlit.io**, войди через GitHub.
2. `New app` → выбери репозиторий `trendradar`, ветку `main`.
3. **Main file path**: `dashboard/app.py`
4. `Deploy`.

Через пару минут получишь ссылку вида `xxx.streamlit.app`, открывается с телефона.
Оговорка: дашборд читает локальную базу, а на Streamlit Cloud её нет. Чтобы
данные доходили, нужен Postgres — следующий шаг.

### Шаг 8 (надёжнее). База вместо кэша

По умолчанию база живёт в кэше GitHub Actions. Кэш может вытесняться, и тогда
история потеряется. Надёжнее — бесплатный Postgres:

1. **neon.tech** → регистрация → `Create project`.
2. Скопируй **Connection string** (начинается с `postgresql://`).
3. GitHub: `Settings` → `Secrets and variables` → `Actions` → `New repository secret`.
4. Name: `TRENDRADAR_DB`, Secret: строка подключения.
5. В `.github/workflows/collect.yml` удали шаги `Restore DB` и `Save DB`
   (при Postgres кэш не нужен) и добавь переменную к шагам запуска:

```yaml
      - name: Collect Roblox
        env:
          TRENDRADAR_DB: ${{ secrets.TRENDRADAR_DB }}
        run: python src/collect.py
```

То же `env:` добавь к `Collect YouTube`, `Collect origins (hourly)` и `Report`.
Затем в Streamlit Cloud → `Settings` → `Secrets` вставь
`TRENDRADAR_DB = "postgresql://..."`, и дашборд увидит данные.

### Как вносить изменения потом

Меняешь файлы на компьютере, затем:

```bash
git add .
git commit -m "что поменял"
git push
```

### Ошибки, которые бывают у всех

| Симптом | Причина | Решение |
|---|---|---|
| `git: command not found` | Git не установлен | шаг 3 |
| `Authentication failed` | введён пароль вместо токена | шаг 5, нужен `ghp_...` |
| `remote origin already exists` | уже добавлял remote | `git remote set-url origin НОВЫЙ_URL` |
| `failed to push some refs` | на GitHub уже есть файлы | `git pull --rebase origin main` |
| Actions не запускается | workflow не включён | шаг 6, пункт 2 |
| Actions: красный крест | упал запуск | открой его, раскрой красный шаг, прочти текст ошибки |
| Дашборд пустой | нет доступа к базе | шаг 8, нужен Postgres |

## Ограничения — честно

- **embed-проход не безупречен.** На выборке ~10% его попаданий спорные
  (слово «Anime» → «Anime Dice», «Kucing» → «Cat Battles» — по смыслу близко,
  по факту это может быть другая игра). Поле `method` позволяет отфильтровать
  и доверять только `link` и `token`.
- **Дельты роста появятся не сразу.** Пока в базе один день, скор опирается на
  ранг в когорте и ограничен 60 из 100 — система не изображает уверенность.
- **Динамика внешних сигналов** тоже начнётся со второго дня.
- **Видим только то, что попало в чарты** — плюс игры, на которые авторы дали
  ссылку (проход `link`). Полный обход каталога Roblox не сделан.
- **GitHub Actions**: cron неточный, запуск может съехать на 5–15 минут. Условие
  «раз в час» привязано к минутам `< 15`; при сильной задержке тяжёлый проход
  может пропуститься на час — данные не теряются.
- **Steam троттлит**: 40 игр ≈ 45 секунд, поэтому опрос раз в час.
- **ToS.** DevForum и YouTube RSS — публичные фиды. Парсинг HTML-поиска YouTube
  против ToS; ограничен `--discover-lang` и `--discover`.
- **Главное.** Система показывает, где спрос. Взлетит ли твоя игра — зависит от
  реализации, и этого она не предскажет.
